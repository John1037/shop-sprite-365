# ShopSprite 365

Shopping assistant web app.

## Structure

- `index.html` – home page
- `css/styles.css` – styles
- `js/main.js` – front-end scripts
- `assets/` – images and logos

## Running locally

Open `index.html` in a browser, or serve the folder with any static server, e.g.:

```
npx serve .
```
